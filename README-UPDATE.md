# Калькулятор освещения — обновлённая версия

## Что входит в проект
- Два режима: «Бытовой» и «Профессиональный».
- Бытовой калькулятор, журнал, сохранение результатов и PWA-функции сохранены.
- Обновлён интерфейс: тёмная сине-графитовая палитра, бирюзовые акценты, карточки и адаптивная сетка.
- Профессиональный режим выполняет предварительную оценку методом коэффициента использования:
  Φ = E × S / (η × MF).
- В профессиональном режиме доступны параметры геометрии помещения, рабочей плоскости, высоты установки, η, MF и светового потока светильника.
- Рабочая плоскость на уровне пола (0 м) допускается, если она находится ниже светильника.
- При ручном вводе количества светильников ниже расчётного показывается предупреждение с оценкой освещённости и рекомендацией увеличить количество или световой поток.
- Внешний файл `calc-light-refresh.css` подключается после встроенных стилей, чтобы его правила корректно переопределяли базовые.
- Service Worker использует cache version `calc-osveschenie-v17`; в офлайн-оболочку включены `index.html`, `calc-light-refresh.css`, `manifest.json` и `icon-512.png`.

## Проверки и ограничения
- Сохранены 14 массивов таблицы коэффициентов, по 17 значений в каждом; 17 индексов помещения.
- Профессиональный режим пока не выполняет точечный расчёт, не импортирует IES/LDT и не подтверждает UGR, равномерность или нормативное соответствие. Для этого нужен следующий этап разработки с фотометрическими данными.
- Формула даёт предварительную оценку среднего уровня освещённости и не заменяет полноценный проектный светотехнический расчёт.
