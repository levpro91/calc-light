# Калькулятор освещения — обновлённая версия

## Что изменено
- Добавлены два режима: «Бытовой» и «Профессиональный».
- Бытовой калькулятор, журнал, сохранение результатов и PWA-функции сохранены.
- Обновлён интерфейс: тёмная сине-графитовая палитра, бирюзовые акценты, карточки и адаптивная сетка.
- Профессиональный режим выполняет предварительную оценку методом коэффициента использования:
  Φ = E × S / (η × MF).
- Добавлены поля геометрии, рабочей плоскости, высоты установки, η, MF и светового потока светильника.
- Service Worker cache version обновлён до v14.
- Проверено: 14 массивов таблицы коэффициентов, по 17 значений в каждом; 17 индексов помещения.

## Важно
Профессиональный режим пока не выполняет точечный расчёт, не импортирует IES/LDT и не подтверждает UGR, равномерность или нормативное соответствие. Для этого нужен следующий этап разработки с фотометрическими данными.

## Установка на GitHub Pages
Заменить в корне репозитория файлы:
- `index.html`
- `service-worker.js`
- `manifest.json`

`icon-512.png` оставлен без изменений.
