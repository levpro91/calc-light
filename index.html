Расчёт освещения

Подбор светового потока для помещений

Чтобы установить приложение:
нажмите «Поделиться» (квадрат со стрелкой) и выберите «На экран „Домой“»
Диапазон: 1–700 лк
Поле станет доступно после выбора подвесного светильника. Для потолочного светильника опуск принимается равным 0 м.
Значение задаётся в метрах независимо от выбранных единиц размеров комнаты. Для пола как рабочей поверхности укажи 0 м.
Выбери помещение — калькулятор подставит среднее значение E. Можно поправить вручную.
Как выбрать по цвету отделки
70% — очень светлоеБелый, молочный, почти белый
50% — светлоеСветло-бежевый, пастельный, светло-серый
30% — среднееСерый, цветное дерево, насыщенные оттенки
10% — тёмноеГрафит, тёмное дерево, тёмно-коричневый

Порядок значений: потолок / стены / пол. Ориентируйся на ближайший вариант отделки. Если сомневаешься между двумя, выбери более тёмный — это даст более осторожную оценку.

Это ориентиры, а не точное измерение: фактическое отражение зависит от материала, фактуры и блеска поверхности.
2. Распределение по лампам / линиям
Сколько света теряется на экране (в процентах).
Например: матовый рассеиватель — 20%, сетка — 40%, плотный фильтр — 60%.
